# 玄鉴网站与使用手册图标

本目录保存从“文件格式图标”素材包复制的 SVG 图标，原始下载文件未做修改。

## 目录

- `file-types/`：文件格式与内容类型图标，用于支持格式、文件列表和格式说明。
- `file-actions/`：上传、新建、移动、打开文件夹等操作图标，用于知识空间和文件管理说明。
- `knowledge/`：科研、数据和知识库相关图标。

## 使用建议

- 同一区域优先使用同一风格的图标。
- 彩色文件格式图标适合“支持的文件格式”与文件列表。
- 黑色线性操作图标适合使用手册中的操作入口与步骤说明。
- 首页技能滚动区暂不混用这套图标，避免与现有线条图标产生风格冲突。
